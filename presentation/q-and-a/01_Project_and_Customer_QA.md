# Order2Me Q&A — Member 1

တာဝန်ယူရန် — Project overview, problem, customer workflow နှင့် project differentiation

## လေ့ကျင့်ရန် စကားပြောပုံ

**ဆရာမ:** Order2Me ကို ဘာကြောင့်တည်ဆောက်ခဲ့တာလဲ?

**အဖွဲ့ဝင်:** ကျွန်တော်တို့ကျောင်းရဲ့ အဆောင်နေကျောင်းသား၊ ကျောင်းသူတွေက canteen ကနေ အစားအသောက်မှာယူတဲ့အခါ ဖုန်းဆက်ပြီးမှာယူနေရပါတယ်။ ဒီလိုမှာယူတဲ့အခါ ဖုန်းလိုင်းပြတ်တာ၊ ဆိုင်မှာ ဘာတွေရနိုင်လဲမသိတာ၊ order အချက်အလက်တွေ မှားယွင်းမှတ်တမ်းတင်မိတာနဲ့ လက်ရှိ order အခြေအနေကို မသိနိုင်တာတွေ ဖြစ်တတ်ပါတယ်။ ဒီ manual process ကို ပိုလွယ်ကူပြီး စနစ်ကျတဲ့ digital process အဖြစ်ပြောင်းဖို့ Order2Me ကိုတည်ဆောက်ခဲ့တာဖြစ်ပါတယ်။

**ဆရာမ:** Foodpanda ရှိပြီးသားဆိုတော့ Order2Me က ဘာကြောင့်လိုသေးတာလဲ?

**အဖွဲ့ဝင်:** Foodpanda က မြို့အနှံ့စားသောက်ဆိုင်တွေအတွက် general commercial platform ဖြစ်ပါတယ်။ Order2Me က UCSY အဆောင်နဲ့ canteen ကြားက workflow အတွက်သီးသန့်တည်ဆောက်ထားပါတယ်။ ကျောင်းတွင်းဆိုင် approval၊ လက်ရှိ menu availability၊ အဆောင် delivery နဲ့ Customer–Owner တိုက်ရိုက်ဆက်သွယ်မှုကို အဓိကထားပါတယ်။ Foodpanda နဲ့ယှဉ်ပြိုင်တာမဟုတ်ဘဲ UCSY ရဲ့လက်ရှိ phone-ordering ပြဿနာကို ဖြေရှင်းတာဖြစ်ပါတယ်။

**ဆရာမ:** Project ရဲ့ အရေးအကြီးဆုံး feature က ဘာလဲ?

**အဖွဲ့ဝင်:** Customer၊ Owner နဲ့ Admin တို့ကို complete workflow တစ်ခုအဖြစ် ချိတ်ဆက်ထားခြင်းပါ။ Customer တင်တဲ့ order ကို Owner က realtime လက်ခံနိုင်ပြီး Owner ပြောင်းတဲ့ status ကို Customer က ချက်ချင်းမြင်နိုင်ပါတယ်။ ဆိုင်အသစ်ကိုလည်း Admin အတည်ပြုပြီးမှ Customer ဘက်မှာပေါ်စေပါတယ်။

**ဆရာမ:** Customer က account မဖွင့်ဘဲ order တင်လို့ရလား?

**အဖွဲ့ဝင်:** မရပါဘူး။ Order ကိုဘယ်သူတင်ထားတယ်ဆိုတာသိဖို့၊ Customer နဲ့ပြန်ဆက်သွယ်နိုင်ဖို့၊ ကိုယ့် order history ကိုကိုယ်ပဲကြည့်နိုင်ဖို့နဲ့ order အတုတွေကို လျှော့ချဖို့ verified account လိုအပ်ပါတယ်။ Account မရှိတဲ့ Customer ကို order တင်ခွင့်ပေးထားရင် order ownership နဲ့ security ပြဿနာတွေ ဖြစ်နိုင်ပါတယ်။

**ဆရာမ:** Email confirmation ကို ဘာကြောင့်ထည့်ထားတာလဲ?

**အဖွဲ့ဝင်:** Account ဖွင့်သူက ထည့်ထားတဲ့ email inbox ကို အမှန်တကယ်အသုံးပြုနိုင်ကြောင်း စစ်ဆေးဖို့ဖြစ်ပါတယ်။ Email ထဲကို OTP code ပို့ပြီး အဲဒီ code ကိုမှန်ကန်စွာထည့်နိုင်မှ account ကို confirm လုပ်ပေးပါတယ်။ Verified email ရှိတာကြောင့် password မေ့သွားရင်လည်း account ကိုလုံခြုံစွာပြန်ယူနိုင်ပါတယ်။

**ဆရာမ:** Password မေ့သွားရင် ဘယ်လိုပြန်ယူမလဲ?

**အဖွဲ့ဝင်:** Forgot Password မှာ account email ကိုထည့်လိုက်ရင် reset OTP code ကို email ထဲပို့ပေးပါတယ်။ Code မှန်မှသာ password အသစ်ပြောင်းနိုင်ပါတယ်။ ဒါကြောင့် email address သိရုံနဲ့ တခြားသူက password ပြောင်းလို့မရပါဘူး။

**ဆရာမ:** ဖုန်းနံပါတ်ကို မဖြစ်မနေဘာကြောင့်ထည့်ခိုင်းတာလဲ?

**အဖွဲ့ဝင်:** Delivery location မရှင်းတာ၊ payment မကိုက်တာ၊ item မရနိုင်တော့တာနဲ့ Customer ကို delivery သွားပို့ချိန် ရှာမတွေ့တာမျိုးမှာ Owner ကတိုက်ရိုက်ဆက်သွယ်နိုင်ဖို့ဖြစ်ပါတယ်။ ဒါကြောင့် ဖုန်းနံပါတ်ဟာ feedback အတွက်တင်မဟုတ်ဘဲ order fulfillment အတွက်လိုအပ်တဲ့ contact information ဖြစ်ပါတယ်။

**ဆရာမ:** Customer က order တင်ပြီးမှ cancel လုပ်လို့ရလား?

**အဖွဲ့ဝင်:** လက်ရှိ Version 1 မှာ Customer ဘက်ကနေ တိုက်ရိုက် cancel မလုပ်နိုင်သေးပါဘူး။ Customer က payment ပြုလုပ်ထားနိုင်သလို ဆိုင်ကလည်း အစားအသောက်စပြင်နေပြီဖြစ်နိုင်တဲ့အတွက် refund နဲ့ preparation policy လိုအပ်ပါတယ်။ Cancel လုပ်ဖို့လိုရင် Owner ကိုဆက်သွယ်ရပါတယ်။ နောက် version မှာ Pending အဆင့်အတွင်း cancel request တင်နိုင်တဲ့ workflow ထည့်နိုင်ပါတယ်။

**ဆရာမ:** Notification ပိတ်ထားရင် status ကိုဘယ်လိုသိမလဲ?

**အဖွဲ့ဝင်:** Push notification မရပေမယ့် order data မပျောက်ပါဘူး။ Customer က Order2Me ထဲဝင်ပြီး Order History မှာ လက်ရှိ status ကိုကြည့်နိုင်ပါတယ်။ App ဖွင့်ထားရင် realtime update ကိုလည်းမြင်နိုင်ပါတယ်။ Notification က background မှာအသိပေးတာဖြစ်ပြီး order status ရဲ့မူရင်း data မဟုတ်ပါဘူး။

**ဆရာမ:** လက်ရှိ Order2Me ရဲ့အားနည်းချက်က ဘာလဲ?

**အဖွဲ့ဝင်:** Payment verification ကို Owner က manually စစ်ရပါတယ်။ Customer-side cancellation နဲ့ automatic refund မပါသေးပါဘူး။ Internet မရှိရင် order တင်လို့မရသလို notification က browser permission ပေါ်မူတည်ပါတယ်။ ဒီအချက်တွေကို Version 1 ရဲ့ limitations အဖြစ်သတ်မှတ်ထားပြီး pilot feedback ပေါ်မူတည်ကာ ဆက်လက်ပြင်ဆင်မှာဖြစ်ပါတယ်။

## မှတ်ထားရန်

Order2Me ကို “Food delivery website” လို့ပဲ မပြောပါနှင့်။ “UCSY hostel students, canteen owners and administrators ကိုချိတ်ဆက်ထားတဲ့ complete ordering workflow” လို့ပြောပါ။
